# VideoKit 4.6.6-beta (测试版)

> 🧪 **测试版说明**：在 `4.6.5-beta` 基础上新增 **T 字幕 32 款小图标库下方内联调节栏（大小 / 左右X / 上下Y / 角度 / 动效）** 与 **字幕上方 / 字幕下方 / 底部居中** 快速定位按钮，完整对齐滚动字幕调节体验。

## 本次 4.6.6-beta 核心更新

### 1. 🎛 T 字幕小图标调节体验对齐滚动字幕（所见即所得 + 底部快捷定位）
- **T 字幕图标库默认展开 + 内联调节栏**：在 **T 字幕 -> 3. 字幕背景与装饰** 内，32 款圣诞小图标下方直接新增 **大小 / 左右X / 上下Y / 角度 / 持续动效 / 删除** 滑块栏（同时支持 **📍 画面小图标** 与 **✍️ 字幕跟读小图标** 两种模式实时微调）。
- **新增字幕下方与底部快速对齐**：无论是 **T 字幕** 的内联调节栏，还是 **🖼️ 覆层** 贴纸检查器，均新增 **`💬 字幕下方`**、**`⬇ 底部居中`**、**`↙ 左下角`**、**`↘ 右下角`** 一键放置按钮（保留 **`🌲 树顶上方`**、**`💬 字幕上方`**、**`🎯 画面中心`**），点顶部 **`+ 🎄 放画面小图标(32款)`** 直接在 T 字幕内展开并定位到图标+调节区，无需跳走。

### 2. 🎄 完整包含 `4.6.5-beta` 32 款立体圣诞小图标库 & 圣诞字幕组合
- **32 款渐变高光+立体投影小图标**（覆盖 **🔔 圣诞经典**、**⛄ 萌物人物**、**🌟 圣夜信仰**、**🍪 冬日美食** 4 大分类），既可作为画布自由拖拽贴纸 (`sticker`)，也可作为跟读笔尖/伴随图标。
- **`sub-245`～`sub-250` 圣诞全样式预设** 与 **8 套一键黄金组合**（树顶金色双铃铛 + 翡翠绿胶囊双行白字、水晶体雪球 + 冰雪底条等）。

### 3. ☁️ 延续 `4.6.4-beta` 全部云端与创意覆层能力
- 云服务器 `videokit-cli update` 自更新、`scripts/cloud-update.sh`、`bin/videokit-web-server.cjs` 防旧 `dist/` 自动热切、`intro_countdown` 倒计时圆环开场、`ov-16`~`ov-35` 创意祈祷卡片与 Muse 导入等全部包含。
