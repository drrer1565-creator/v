# VideoKit 4.6.8 (正式版)

## 本次 4.6.8 正式版核心更新（整合 4.6.3-beta ~ 4.6.8-beta 全量新特性与修复）

### 1. 🪶 40 款高颜值矢量小图标（贴纸与打字机/跟读通用）+ 红雀鸟专属飞羽系列
- **新增 8 款飞羽与红雀鸟精美矢量图标**：包含专为 Northern Cardinal（红雀鸟）主题打造的 **`🪶 红雀红褐色羽毛` (`cardinal_feather`)**、**`🐦 红雀鸟松枝` (`northern_cardinal`)**，以及 **`✒️ 红雀棕羽金笔`**、**`🍂 焦糖琥珀金羽`**、**`🥀 绯红玫瑰金羽`**、**`❄️ 冰晶银蓝雪羽`**、**`🦚 翡翠孔雀翎羽`**、**`🕊️ 圣洁鎏金白羽`**。
- **32 款圣诞与冬日节日系列同步转正**：雪白和平鸽、驯鹿、圣诞老人、糖果手杖、蝴蝶结礼物、伯利恒之星、十字架、圣诞树等 **40 款**内置矢量图标全部支持画布自由拖拽贴纸与文字跟读笔尖（面板支持 **`🪶 红雀羽毛`**、**`🔔 圣诞经典`**、**`⛄ 萌物人物`** 等分类一键筛选），并配备顶栏快捷按钮 **`🪶 红雀红褐羽毛+出字`** 与 **翡翠胶囊组合预设（`sub-245` ~ `sub-250`）**。

### 2. 💬 T 字幕「按整句 (逐句)」出字跟随 + 下方内联微调栏
- 在 **T 字幕 → 打字机参数 → 显示单位** 正式支持 **`按整句 (逐句)` (`sentence`)**，搭配红雀羽毛或任意图标即可整句显现并伴随图标平滑跟读（点击快捷图标时保留已选「逐句」模式，不再强制重置）。
- T 字幕图标选择面板下方新增 **大小 / X偏移 / Y偏移 内联滑动调参栏**，并支持跟随图标 **上方 / 下方放置切换**，操作与滚动字幕保持一致。

### 3. 🔗 媒体跟随滚动字幕稳定性全面修复与边界锁距工具
- 修复多任务同步、暂停状态下播放入场动画及逐帧预览/导出时出现的 **媒体跟随失灵、高度测算偏差与点击选框偏移** 问题，确保预览与所见即所得导出（WYSIWYG）位置完全一致。
- 跟随参数面板新增 **`🧲 保持当前间距`**（一键按当前画布位置锁入偏移并清除不合理夹逼）与 **`↺ 清空边界`** 快捷操作。

### 4. 🎬 圣诞/创意滚卡预设、倒计时圆环片头与云端服务端热更新能力
- 新增创意/沉思风格及圣诞场景滚卡预设，支持 **倒计时圆环片头** 与优化后的自动着色关键词换行/选色交互。
- 强化分标签页水印隔离、本地默认模板兜底、零追加同步策略，以及 Web 服务端一键自助更新脚本支持。
