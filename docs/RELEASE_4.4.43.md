# VideoKit 4.6.3-beta (测试版)

> 🧪 **测试版说明**：面向内测与早期验证发布，如需稳定生产环境可随时切换回正式版通道。

## 本次 4.6.3-beta 核心更新

### 1. 🏷️ 水印系统重构：按标签专属隔离 + 本机默认回退，彻底杜绝工程叠加重复水印
- **启动与恢复自动去重**：归一化 `assets/...` 与 `local-media:///...` 内置图片路径键，自动清理历史因多工程追加而重复累积的文字/图片水印条目，并添加一键 **🧹 清理重复** 与 **↺ 重置默认** 按钮。
- **永不追加叠加**：无论从「工程项目」、「模板库」、本地 JSON/ZIP 还是「云端工程中转站」导入（覆盖或追加模式），均采用最新去重后的水印集合直接设置，**绝不再把水印无限拼接叠加**。
- **按视频标签专属水印 + 本机默认回退**：
  - 每个视频标签若带有专属水印（例如从云端拉取的外部团队工程），切换到该标签或导出该标签任务时自动使用其 **🏷️ 当前标签专属水印**，不会污染本机默认水印与其他标签。
  - 没有设置专属水印的标签自动使用 **🖥️ 本机默认水印**。
  - 水印面板顶部新增作用域状态栏，支持一键 **📌 设为当前标签专属**、**↺ 改用本机默认水印**、**⬆️ 设成本机默认**。
- **输入框焦点与滑块控制修复**：调整滑块、颜色或勾选框时仅重绘画布并更新数值徽标，不再整表销毁重建 DOM，彻底解决水印控制失灵与输入打断问题。
