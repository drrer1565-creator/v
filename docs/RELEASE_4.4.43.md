# VideoKit 4.6.8-beta (测试版)

> 🧪 **测试版说明**：在 `4.6.7-beta` 基础上重磅新增 **红雀红褐色羽毛 (`cardinal_feather`) + 红雀鸟 (`northern_cardinal`) 等 8 款绝美飞羽与动物小图标**（图标库扩展至 **40 款**），并打通 **T 字幕「逐句」模式跟随小图标**。

## 本次 4.6.8-beta 核心更新

### 1. 🪶 新增红雀红褐色羽毛 + 8 款绝美飞羽/红雀小图标（共 40 款，贴纸与跟读通用）
- **`🪶 红雀红褐色羽` (`cardinal_feather`)** & **`🐦 红雀鸟松枝` (`northern_cardinal`)**：专为 **Northern Cardinal（红雀鸟）** 主题视频精心绘制红褐色层次羽翼与写实红雀停枝图。
- **更多高颜值绝美羽毛**：同步新增 **`✒️ 红雀棕羽金笔`**、**`🍂 焦糖琥珀金羽`**、**`🥀 绯红玫瑰金羽`**、**`❄️ 冰晶银蓝雪羽`**、**`🦚 翡翠孔雀翎羽`**、**`🕊️ 圣洁鎏金白羽`**。
- 全部 8 款均同时作为 **画面自由拖拽贴纸 (`sticker`)**、**T 字幕跟读小图标**、**全屏打字机笔尖** 与 **滚动字幕笔尖** 生效，并在面板中新增 **`🪶 红雀羽毛`** 专属分类标签一键筛选。

### 2. 💬 打通 T 字幕「按整句 (逐句)」出字 + 小图标跟随
- 在 **T 字幕 → 打字机参数 → 显示单位** 中正式新增 **`按整句 (逐句)` (`sentence`)** 选项；搭配 `🪶 红雀红褐色羽毛` 或任意图标即可整句显现并伴随图标平滑跟读（点击快捷图标时自动保留当前已选的「逐句」设置，不再被重置）。
- 滚动字幕的 **逐句出现 (`sentence`)**、全屏打字机 **逐句出现** 也均可直接使用全部 40 款小图标。

### 3. 🔗 完整包含 `4.6.7-beta` 媒体跟随与此前全量能力
- 完整保留多任务跟随重映射、预览/导出精准测算、`🧲 保持当前间距` / `↺ 清空边界`、T 字幕内联下方滑块与上下放置、`sub-245`~`sub-250` 圣诞组合等全部功能。
