# VideoKit 4.6.7-beta (测试版)

> 🧪 **测试版说明**：在 `4.6.6-beta` 基础上全面修复 **「媒体/贴纸跟随滚动字幕」多任务同步串ID、预览/导出测算错位、入场选中时间偏移与边界坐标误填锁死** 等间歇性失灵问题。

## 本次 4.6.7-beta 核心更新

### 1. 🔗 修复「媒体跟随滚动字幕」有时候失灵问题
- **修复批量/多任务样式同步断绑**：此前编辑队列任一任务的绑定媒体时，样式同步会把第 1 条任务的 `scroll` ID 原样覆写到第 2、3、4… 条任务上导致后面所有任务失灵；现已改为按目标任务自动重映射对应滚动层 ID 与模板槽位 ID。
- **修复预览与导出的时间/段落测算错位**：
  - 选中带入场动画的绑定媒体时，固定以原始时间轴时间测量滚动首行，不再超前跳帧。
  - 修复 `ReelsPreviewV2`、普通预览及 `WYSIWYG` 导出时二次 `proxy` 用未解析时长 (`end=9999`) 或丢失 `_taskSegments` 覆盖真实首行 Y 的问题；导出中 `scroll` 清理自身 `_taskSegments/_exporting` 后，绑定媒体会自动透传给测算代理。
  - 修复绑定媒体选框（`getOverlayBounds` / `_ovGetBounds` / `hitTest`）仍停留在旧坐标或被 `A→B` 终点覆盖的问题，点击拖拽与蓝框完整跟随当前显示位置。
- **防误填锁死 & 一键对齐间距**：
  - 支持在绑定面板一键点 **`🧲 保持当前间距`** 自动计算 `Y偏移`，新增 **`↺ 清空边界`**；明确提示边界坐标为画布 `0(顶)~1920(底)`，填反上下边界时自动交换保护，填写 `≤0` 下边界时给出黄色防踩坑预警。

### 2. 🎄 完整保留 `4.6.6-beta` 与 `4.6.5-beta` 全部能力
- **T 字幕 32 款圣诞图标库 + 下方内联调节栏**（大小 / 左右X / 上下Y / 角度 / 动效 / 上下方快捷对齐）+ 8 套圣诞搭配 + `sub-245`~`sub-250` 圣诞字幕预设。
- 云端 `videokit-cli update` 自更新、`intro_countdown` 倒计时圆环、`ov-16`~`ov-35` 祈祷卡片与 Muse 导入全部包含。
