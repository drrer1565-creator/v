# VideoKit v4.6.11 — 模板重命名、覆层设置与多标签对齐修复

- 修复模板库右键重命名无法输入、取消后再次点击无反应的问题。重命名改用独立输入框，支持取消和重复修改。
- 修复正常素材每隔约 15 秒误触发预览重载、导致滚动覆层设置收起的问题；真实素材状态变化时保留当前覆层选中状态。
- 修复并发对齐期间切换标签页后读取错误文案、候选池或设置的问题。任务在开始时固定音频、文案、语言和所属标签页，结果按任务 ID 写回原标签页。
- 中途修改音频或文案时提示重新对齐，避免旧结果覆盖新内容；删除任务后不把结果写入其他标签页。
- 保留重复音频与文案的字幕复用，以及 v4.6.10 的列显示记忆、v4.6.9 的缺失素材恢复修复。
- 修正旧 CLI 测试中硬编码的 3.00 秒署名时长断言，按实际音频探测后的输出时长验证（如 3.03 秒），不改变导出逻辑。
